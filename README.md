# 高瀬さんの筋トレ応援アプリ

▶ **https://ayumisan.github.io/slot-036/**

トレーナーの高瀬航（たかせ わたる）さんが、筋トレの回数を声で数えて、とにかく褒めてくれるWebアプリです。インストール不要・無料・キー不要で使えます。

## 使い方

1. 上のURLをスマホかパソコンのブラウザで開く
2. メニューを選ぶ（スクワット／腕立て／腹筋／プランク（秒数））
3. 回数（プランクは秒数）・セット数・休憩秒数・テンポを決める
4. 「スタート」を押す。高瀬さんが「いーち、にー…」と数えてくれます
5. 途中で「一時停止」「やめる」もOK。やめても怒られません

> **iPhone の場合**：音が出ないときは、画面を一度タップしてから「スタート」を押してください。マナーモードだと読み上げが聞こえないことがあります。

## 褒め方がメイン

- セットの途中・セット終わり・全部終わったときに、毎回ちがう言葉で褒めてくれます（最近使ったセリフは避けます）
- 自己ベストを更新すると「前回より○回増えてます」
- 3日・7日・14日・30日連続でお祝い
- 久しぶりに来ても責めずに「おかえりなさい」
- 途中でやめても「今日やっただけで偉いっすよ」
- 「キレてる！」「肩にでっかい重機乗せてんのかい！」などのボディビルの掛け声は、たまにだけ
- 高瀬さんの表情がカウントや褒め言葉に合わせて切り替わって、ぴょこっと動きます
- 高瀬さんにとってあなたは、お客さんの小野寺由衣さん。最初から「由衣さん」と呼んでくれます（毎回ではなく、ここぞというときに自然に）。丁寧な「っすよ」口調で、あたたかく、ちょっとだけからかうことも
- 呼び名は設定の「呼んでほしい名前」で変えられます（空にすると名前なしで話します）

## Gemini で自由におしゃべり（任意）

設定を開いて Google AI Studio の Gemini API キーを入れると、Gemini Live で高瀬さんと声で自由に会話できます（高瀬さんは由衣さん＝設定した呼び名のあなたとして話しかけてくれます）。キーはこのブラウザの中（localStorage）にだけ保存され、どこにも送られません（Google への接続以外）。使わなくてもアプリは全部使えます。

## 記録について

日付・メニュー・回数の記録と連続日数は、**このブラウザの中だけ**に保存されます。サーバーには送られません。別の端末やブラウザとは共有されず、ブラウザのデータを消すと記録も消えます。
