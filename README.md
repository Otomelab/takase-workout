# 高瀬さんの筋トレ応援アプリ

トレーナーの高瀬航（たかせ わたる）さんが、筋トレの回数を声で数えて応援してくれる静的Webアプリ（`docs/`）。

- メニュー：スクワット／腕立て／腹筋／プランク（秒数）。回数・セット・休憩・テンポを選べる
- 声：ブラウザの読み上げ（Web Speech API, ja-JP）で「いーち、にー…」。無料・キー不要
- **褒め方が主役**：セット途中・セット終わり・全部終わり・自己ベスト・連続日数（3/7/14/30日）・久しぶりの「おかえり」・途中でやめても「今日やっただけで偉いっすよ」。最近使ったセリフは避けて毎回ちがう言い方。ボディビルの掛け声はたまにだけ
- 高瀬さんの表情（slot-097 の2Dイラスト）がカウントや掛け声で切り替わって、ぴょこっと動く
- 記録は localStorage（日付・メニュー・回数）、連続日数を表示
- 任意：Gemini Live モードで高瀬さんと自由に会話（AI Studio のキーはブラウザの localStorage にだけ保存）
